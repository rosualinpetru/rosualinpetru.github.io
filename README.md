# rosualinpetru.github.io

Personal static HTML website generated by a single Scala script
([`build.scala`](build.scala), using [Laika](https://typelevel.org/Laika/) for markdown),
hosted for free on GitHub Pages.

## Editing content

Pages live in `content/pages/` as markdown files with a two-line header:

```markdown
Title: Research
Slug: research

Body in markdown. Raw HTML blocks also work.
```

Commit and push. GitHub Actions builds and deploys automatically in about a minute.

## Local preview

Requires [scala-cli](https://scala-cli.virtuslab.org/) (`brew install scala-cli`):

```bash
scala-cli run build.scala            # builds the site into output/
python3 -m http.server 8000 -d output
# open http://localhost:8000
```

## Structure

- `build.scala`: the entire site generator (Scala 3)
- `content/pages/`: standalone pages (about/home, research, projects)
- `content/extra/`: files served as-is (`cv.pdf`)
- `static/css/style.css`: the one stylesheet (light + dark via `prefers-color-scheme`)
- `.github/workflows/deploy.yml`: build and deploy on push to `main`

Site name, navigation, social links, and the contact email are constants at the top of
`build.scala`. The email is rendered as plain text with `(at)` to keep it away from
address crawlers.

## Colors

The entire palette (light and dark theme) is derived at build time from the dominant
saturated hue of `static/img/portrait.jpg`: swap the photo and the site recolors itself.
To pin a color manually instead, set `AccentOverride = Some("#146b3a")` in `build.scala`.
`static/css/style.css` never hardcodes a color; everything comes from the generated
`css/palette.css`.

## Updating the CV

Replace `content/extra/cv.pdf` and push.
